# Style C2 夜樱轻奢精修设计

## 目标

把当前 `Style C2 · 甜心饰品风` 收敛成更接近最终审美的精修稿：保留明显的二次元少女向特征，但从“贴纸 / 饰品感”升级为更完整的“夜樱轻奢世界观”。新的预览需要同时让前台登录页与后台配置页成立，并且在亮色、深色、桌面端、移动端四种状态下都保持统一主题语言。

## 当前问题

当前 C2 已经具备较强的少女风记忆点，但仍有三个偏差：

1. 装饰语汇更接近甜品贴纸，不够夜樱梦幻。
2. 视觉记忆点有了，但精致度和高级感不足。
3. 深色模式具备方向感，但还不像完整世界观；后台也需要更像真实可用的产品界面，而不只是装饰化展示。

## 本轮精修结论

### 1. 主题定位

新版 C2 的主方向定为：**夜樱轻奢世界观**。

它不是继续叠加蝴蝶结、徽章、贴纸，而是把视觉语言调整为：

- 樱花 / 月光 / 夜樱花瓣作为主装饰语汇
- 珠光、雾面、细描边、柔辉光作为高级感来源
- 明显统一前后台
- 氛围感强，但仍然保留产品界面可读性

### 2. 风格关键词

- 夜樱紫
- 雾粉
- 月光银
- 冷莓红
- 珠光半透
- 细描边
- 花瓣飘落
- 月弧轮廓
- 轻奢少女
- 二次元正式产品感

### 3. 强度结论

本轮采用**氛围型**强度：页面本身就应拥有明确世界观，而不只是把装饰藏在边角里。用户一眼就要能看出它是少女向、夜樱向、精致向。

## 页面设计

### 登录页

登录页从“甜心入口”升级为“夜樱世界入口”。

#### 保留项

- 继续使用单页内同时展示 desktop / mobile / light / dark 的方式
- 继续使用左侧氛围区 + 右侧登录卡的桌面结构
- 继续保留移动端单列登录卡展示

#### 调整项

1. **Hero 区**
   - 从甜心收藏感改为夜樱世界观入口
   - 标题区使用月光、樱瓣、花雾层次表达氛围
   - 文案不再强调“贴纸收藏”，而强调进入一套完整夜樱产品世界

2. **登录卡**
   - 从“徽章卡片”升级为“珠光登录匣”
   - 表现特征为：细边框、柔和高光、层叠阴影、干净字段节奏
   - 输入区保持明确可读，不做过量装饰

3. **按钮**
   - 主按钮改为夜樱渐变宝石按钮
   - 次按钮改为克制的月雾副按钮
   - 减少糖果按钮感，提升正式产品感

4. **装饰元素**
   - 弱化直白的星点 / 蝴蝶结存在感
   - 改为花瓣漂浮、月弧轮廓、背景雾层、边缘珠光
   - 装饰主要服务世界观，不与登录路径竞争

5. **亮暗主题关系**
   - 亮色：`晨樱珠雾`，强调轻盈、半透、柔光
   - 深色：`夜樱月下`，强调完整夜樱主视觉，不是简单反色

### 后台配置页

后台保持与登录页统一的世界观，并且统一程度要明显。

#### 基本原则

后台必须像真的可用，而不是一张装饰海报。

#### 保留项

- 保留真实后台结构：标题、刷新、保存配置、警告、分组标题、字段卡片
- 保留 `createInput(...)` 体现出来的字段语义：统一字段容器、label、help、input/select
- 保留配置页的真实信息节奏

#### 调整项

1. **整体场景**
   - 外层背景改为夜樱轻奢场景
   - 顶部和边角可以出现月弧、花瓣、柔光层
   - 信息区内部保持稳定，不做噪声化装饰

2. **配置卡片**
   - 从“收藏柜 / 饰品卡”改为“珠光配置匣 / 樱雾模块卡”
   - 更细的边框、更清楚的内外层级、更克制但更贵的高光处理

3. **字段控件**
   - label 像正式产品字段标题
   - help 更轻、更细、更柔和
   - input/select 更像品牌化控件，而不是普通管理台默认样式

4. **操作区**
   - `保存配置` 保持强 CTA，但做成夜樱宝石质感
   - `刷新` 做成更克制的月雾副操作
   - 风险提示区仍然明显，但视觉上融入主题体系

5. **装饰控制**
   - 装饰集中在标题区、分组边角、卡片辉光、背景层
   - 不把装饰塞进每一个输入框内部
   - 保证后台仍然具有扫读性、操作感、配置感

## 交付范围

本轮不重新创建新的大方向风格，而是直接在已选中的 C2 基础上新增一组 refine 预览。

### 输出文件

- `ui-previews/style-c2-refine-login.html`
- `ui-previews/style-c2-refine-admin.html`
- `tests/test_ui_previews_style_c2_refine.py`

### 每个 HTML 文件必须同时展示

- desktop + light
- desktop + dark
- mobile + light
- mobile + dark

继续使用 2×2 预览布局，方便直接比较亮暗主题与桌面/移动端状态。

## 测试要求

测试文件需要校验：

- `data-style="c2-refine"`
- `data-page="login"` / `data-page="admin"`
- `data-preview-mode="desktop"`
- `data-preview-mode="mobile"`
- `data-theme-preview="light"`
- `data-theme-preview="dark"`
- 登录页包含夜樱轻奢相关关键文案与 CTA
- 后台页包含系统配置、保存配置、至少一个真实字段语义
- 不包含 `scripts/main.new.js`
- 不包含 `fetch(`

## 非目标

本轮不做以下工作：

- 不接入真实业务 JS
- 不接入真实配置逻辑
- 不改现有主站页面
- 不回到 A / B / C 大方向重新比较
- 不把本轮扩展成新的整套风格家族

## 验收标准

当用户打开 refine 预览时，应能直接感受到：

1. 这是在 C2 基础上的升级，而不是换成另一套风格。
2. 风格从“甜心饰品”提升为“夜樱轻奢少女产品”。
3. 深色模式像完整世界观，不是普通暗色换皮。
4. 前后台明显统一。
5. 后台依然像真正可读、可操作的配置界面。

## 实测发现并修复

- 高德 SDK 会将协议与服务主机分别拼接，提前改写片段会产生错误主机。现在保留片段，在请求入口改写最终 URL。
- 高德部分 JSONP 返回 JSON 或二进制 MIME；保留 `nosniff`，只对通过严格回调和 JSON 校验的响应纠正 MIME。
- 天地图用 `innerHTML` 和内联 CSS 创建 logo，单独拦截 `img.src` 不够；补齐 HTML/CSS 入口。
- 百度存在根路径查询及多余根斜杠；代理必须支持这些路径，不能由 Flask 返回本地 404。
- 百度 Blob Worker 内部的脚本、fetch 和 XHR 不经过页面钩子；已在 Worker 作用域安装代理。当前 SDK 使用的 Blob/classic Worker 链路已实测。
- 代理凭证到期、初始化竞争和续签失败需单独处理。续签只刷新真实调用者，资源请求不增加 Token 写入；失败时保持代理，不恢复直连。
- Nginx 转发保留非默认端口，代理查询串不进入 Nginx 访问/错误日志；统一 Python 日志脱敏覆盖地图凭据及 urllib3 DEBUG。

调试期间曾出现百度上游 `ReadTimeout`；代理返回 502，未回退直连。最终联测和单独复测成功，不代表第三方服务后续不会超时。

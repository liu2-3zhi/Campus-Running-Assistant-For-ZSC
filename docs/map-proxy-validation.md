## 实测发现并修复

- 高德 SDK 会将协议与服务主机分别拼接，提前改写片段会产生错误主机。现在保留片段，在请求入口改写最终 URL。
- 高德部分 JSONP 返回 JSON 或二进制 MIME；保留 `nosniff`，只对通过严格回调和 JSON 校验的响应纠正 MIME。
- 天地图用 `innerHTML` 和内联 CSS 创建 logo，单独拦截 `img.src` 不够；补齐 HTML/CSS 入口。
- 百度存在根路径查询及多余根斜杠；代理必须支持这些路径，不能由 Flask 返回本地 404。
- 百度 Blob Worker 内部的脚本、fetch 和 XHR 不经过页面钩子；已在 Worker 作用域安装代理。当前 SDK 使用的 Blob/classic Worker 链路已实测。
- 代理凭证到期、初始化竞争和续签失败需单独处理。续签只刷新真实调用者，资源请求不增加 Token 写入；失败时保持代理，不恢复直连。
- Nginx 转发保留非默认端口，代理查询串不进入 Nginx 访问/错误日志；统一 Python 日志脱敏覆盖地图凭据及 urllib3 DEBUG。
- 腾讯 `confinfo` 的 `callback&&callback(JSON)` 返回 `text/plain`。现在只为同一个已校验回调和严格 JSON 的完整包装纠正 MIME，仍拒绝额外表达式并保留 `nosniff`；修复后旧版、Vue 的真实腾讯代理均无 MIME 错误。
- Vue 初始化时隐藏地图容器曾令腾讯取得零尺寸；改为保留布局的 `visibility`。天地图改用构造标题及标签，移除不存在的 `Marker.setTitle()`；高德脚本按原始 URL 缓存，避免代理改写 URL 后组件重建重复加载 Loader。
- 修复旧批次状态/快照覆盖新执行、旧版重跑保留完成颜色、慢快照被每轮轮询持续作废，以及多账号刷新缺位置/删除后残留标记。后台启动、状态、停止接口补齐真实调用者、管理员来源与权限校验；游客 Token 索引和实体均作只读验证。

调试期间高德、百度等真实上游多次出现 `ReadTimeout`，代理返回 502，个别 SDK 加载达到截止时间；均未回退直连。随后单独复测成功，不代表第三方服务后续不会超时。不能将这些失败轮次记为通过。

## 复现方式与范围

显式设置 `MAP_SMOKE_CREDENTIALS`，内容为按供应商命名的 JSON；每项包含 `key`、`origin`，高德可另含 `securityJsCode`。然后运行：

```powershell
python tests/browser_map_proxy_smoke.py
```

生产队列来源验收运行 `python tests/browser_map_origin_smoke.py`。Vue 组件模式设置 `MAP_SMOKE_RENDER_UI=1`；旧版模式设置 `MAP_SMOKE_RENDER_LEGACY=1`，分别运行上述代理脚本。`MAP_SMOKE_PROGRESS=1` 可输出各家的安全进度。用于区分 SDK 原生压力异常的直连对照为 `python tests/browser_map_ui_origin_control.py`，它只本地拦截测试页，不从授权域名加载应用页面。

脚本只输出来源、状态、数量、测试坐标断言失败摘要与脱敏错误，运行后关闭浏览器和本地监听。凭据使用完应从当前进程环境删除；不要把实际值写入命令示例、配置或结果文件。

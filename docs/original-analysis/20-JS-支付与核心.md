## 附录 B：全局 DOM id 命名规律（复刻要点）

- **PC/桌面端**统一带 `_modal` 后缀（如 `admin-*_modal`、`payment-methods-list_modal`）；**移动端**多为无后缀或 `-mobile`/`-ctrl` 后缀。

- 结果提示区约定：`*-result*` 容器成功绿色/失败红色，多数 3s（成功）/5–8s（失败）后加 `hidden`。
- 弹窗统一 `Swal.fire`；少量遗留原生 `alert`/`confirm`（`deletePaymentMethod` confirm、`saveMobileWatermarkControlConfig` alert）。
